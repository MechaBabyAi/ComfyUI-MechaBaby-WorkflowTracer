# ComfyUI MechaBaby Workflow Tracer (机械宝宝工作流追踪器)

这是一个专为 ComfyUI 设计的增强型工作流分析与提取工具。它可以实时追踪工作流的执行路径，精确记录每个节点的运行顺序和耗时，并允许你根据实际运行状态提取“热路径”工作流。

## 🌟 核心功能

1.  **实时运行追踪**：
    *   **耀眼高亮**：正在运行的节点以**鲜艳黄色**发光边框显示，已完成的节点保持**翠绿色**发光效果。
    *   **路径可视化**：实际执行过的连线会自动加粗并发出绿光，清晰展示数据的流转路径。
2.  **多重序号与循环支持**：
    *   **序号标注**：节点左上角显示执行序号（如 `#1`）。
    *   **循环记录**：支持循环节点（Loop），自动记录多次运行序号（如 `#5, #12, #19`）。
    *   **智能缩略**：序号过多时自动缩略显示，**鼠标悬停**即可展开查看完整列表。
3.  **精确计时统计**：
    *   **单次计时**：实时显示当前节点的运行秒数。
    *   **累计耗时**：对于循环运行的节点，自动统计所有循环步数的**总耗时** (Total Time)。
4.  **智能工作流提取**：
    *   **🛠️ 纯净提取 (Pure Path)**：仅保留本次运行中实际走过的节点和连线，适合分析逻辑分支。
    *   **🔗 逻辑闭合 (Logic Integrity)**：基于运行节点进行**递归回溯**，自动补全所有依赖的输入源节点，确保导出的工作流拖入即可运行。
5.  **极致兼容性**：
    *   完美支持 ComfyUI 的**现代节点设计 (Vue Nodes)**。
    *   兼容 `Easy-Use` 等第三方插件的无线传输节点（通过序号理清逻辑）。

## 🎮 操作指南

### 1. 控制面板 (Floating Panel)
*   **拖拽移动**：点击面板顶部的标题栏可将其移动到屏幕任何位置。
*   **位置记忆**：面板位置会被自动保存，下次启动时无需重新调整。
*   **一键开关**：点击面板上的 `ON` 复选框可开启或完全静默插件。
*   **快速关闭**：点击右上角的 `×` 可隐藏面板。

### 2. 右键菜单 (Context Menu)
在画布空白处右键，可快速访问：
*   `👁️ Show/Hide Tracer Panel`：唤起或隐藏控制面板。
*   `🛠️ Export: Pure Path`：执行纯净提取。
*   `🔗 Export: Logic Integrity`：执行逻辑闭合导出。
*   `🧹 Mecha Tracer: Clear`：手动清除本次运行记录和高亮。

## 📂 安装说明

1.  进入你的 ComfyUI 插件目录：`ComfyUI/custom_nodes/`。
2.  在此目录下建立文件夹：`ComfyUI-MechaBaby-WorkflowTracer`。
3.  将插件文件放入其中。
4.  重启 ComfyUI 即可。

## 💡 性能说明
*   **零开销**：插件采用纯前端 Canvas 劫持技术，不修改后端 Python 逻辑，完全不影响图像生成的采样速度。
*   **稳健性**：针对超大型工作流进行了优化，导出逻辑采用纯 JSON 递归回溯，杜绝浏览器崩溃或报错。
