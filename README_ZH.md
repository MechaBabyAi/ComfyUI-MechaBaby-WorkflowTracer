# 🤖 机械宝宝工作流追踪器 (MechaBaby Workflow Tracer)

[English](./README.md) | **简体中文**

专为 ComfyUI 设计的增强型插件，用于记录、可视化并提取工作流中的实际运行路径，帮助从庞大复杂的工作流中精准“脱水”，只保留真正执行过的逻辑。

---

## 🌟 核心功能

### 1. 路径实时可视化
- **执行高亮**：当前正在运行的节点以**黄色**高亮；已完成的节点按角色着色（见下方「节点与连线颜色」）。
- **连线发光**：实际传输数据的连线会高亮；连线颜色表示源节点类型（纯参数源=橙、参数节点=绿、普通已执行=白）。
- **现代 UI 兼容**：支持 ComfyUI 的「现代节点设计 (Vue 节点)」。

### 2. 节点与连线颜色
运行结束后，节点和连线按数据流角色着色：

| 类型           | 颜色   | 含义 |
|----------------|--------|------|
| **当前运行**   | 黄色   | 正在执行的节点 |
| **纯参数源**   | 橙色   | 已执行且**没有任何输入**来自其他已执行节点（如 CheckpointLoader、Empty Latent、仅用文本框的 CLIP）。标签：「(纯参数源)」 |
| **参数节点**   | 绿色   | 已执行且**至少有一条输出**被其他已执行节点使用（如模型→KSampler、KSampler→VAE Decode）。标签：「(参数)」 |
| **普通已执行** | 白色   | 已执行且输出未被任何其他已执行节点使用（如 Save Image、链末节点）。 |

连线颜色与源节点一致：纯参数源连出=橙，参数节点连出=绿，普通已执行连出=白。

### 3. 精准执行统计
- **运行序号**：每个节点显示其执行顺序号（可多个）。
- **耗时**：节点运行时间（秒）；循环节点悬停可查看所有运行序号及累计耗时。
- **循环支持**：多次运行的节点显示紧凑列表，悬停展开。

### 4. 快速跳转报错节点
- **面板**：「⚠️ Jump to Error Node」将画布聚焦到最近一次报错的节点。
- **右键**：画布空白处右键同样可跳转；若有报错记录，菜单会显示报错节点 ID。
- 执行出错时自动记录报错节点。

### 5. 智能工作流提取 (Export)
两种导出模式：
- **🛠️ 纯净路径 (Pure Path)**：仅保存本次运行中真正执行过的节点，适合分析实际执行路径。
- **🔗 逻辑完整 (Logic Integrity)**（推荐）：保留执行过的节点并溯源所有必需祖先（模型加载、全局参数等）。
  - 支持虚拟链路（如 easy-use setNode/getNode、Anywhere 节点）。
  - 保留 GeneralInput 等全局参数节点，导出的 JSON 可直接加载运行。

## 🚀 使用方法

1. **面板**：勾选 **ON** 开启追踪，取消则停止记录（不影响运行效率）。面板可拖拽，位置会记住。
2. **右键**：画布空白处右键可快速开关追踪、显示/隐藏面板、清理记录或跳转报错节点。
3. **循环**：若节点被多次运行，悬停其上方标签可展开完整执行列表与累计耗时。

---

## 🛠️ 安装

1. 进入 ComfyUI 插件目录：`ComfyUI/custom_nodes/`
2. 克隆本项目：
   ```bash
   git clone https://github.com/MechaBabyAi/ComfyUI-MechaBaby-WorkflowTracer.git
   ```
3. 重启 ComfyUI。

---

## ⚖️ 性能说明

本插件仅劫持 LiteGraph 的渲染层，在渲染帧中执行，不修改 ComfyUI 后端 Python 执行逻辑，对图像生成速度影响可忽略。
